# 욜라 W08·W09·W10 병렬 작업 패키지

## 병렬 배치

- W08: 욜라 데이터 결합기
- W09: 전국 중개업소 인터넷 활동 분석기
- W10: 매물 점수 분석기

세 워커는 공통계약과 합성 fixture로 동시에 개발합니다.

## 실제 통합 순서

1. W08 결합기 코어와 출력계약 완성
2. W09가 W08 출력계약을 실제 연결
3. W10이 W08 출력계약을 실제 연결
4. W10이 W09 중개업소 분석결과를 선택적으로 연결
5. W05 완성 공식 원장과 W06 실제 수집결과를 소규모로 통합
6. PostgreSQL·PostGIS 실제 검증

## 현재 주의점

W05 현재 패키지는 공식 원장 부분은 통과했지만 네이버 병합이 미완료인 PARTIAL_RESULT입니다.

W06은 현재 작업지시서만 있고 최종 구현결과가 아직 없을 수 있습니다.

따라서 W08·W09·W10은 코어·계약·fixture·시험을 완료하되 실제 통합 완료라고 보고하면 안 됩니다.
