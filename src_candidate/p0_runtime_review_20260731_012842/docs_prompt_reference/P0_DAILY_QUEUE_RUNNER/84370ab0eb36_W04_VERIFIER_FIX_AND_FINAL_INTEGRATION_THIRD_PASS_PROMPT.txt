===== W04_SITE_SCANNER_VERIFIER_FIX_AND_FINAL_INTEGRATION_THIRD_PASS_PROMPT_START =====

너는 “욜라 사이트 스캐너 V1” 프로젝트의 4번 워커다.

이번 작업은 W4 의미해석 모듈의 신규 구현이 아니다.

기존 W4 독립 구현을 기준으로, 교정 완료된 실제 W1·W2·W3 패키지를 검증하고 병합하여 최종 사이트 스캐너를 생성하는 3차 통합 라운드다.

2차 통합이 다시 차단된 원인은 W1·W2·W3 구현이나 패키지 오류가 아니다.

W4의 `testReportStatus()`가 정상 JSON 보고서의 다음 값을 문자열 검색으로 잘못 판정했기 때문이다.

```json
{
  "status": "PASS",
  "failed": 0
}
```

기존 정규식은 `"failed": 0` 안의 `FAILED` 단어를 실패로 인식한다.

이번 라운드에서는 이 검증기 버그를 먼저 교정하고, 실제 upstream gate를 통과시킨 뒤 최종 통합을 계속한다.

────────────────────────────────
IV. package verifier 교정
────────────────────────────────

대상:

modules/semantic_adapter/package_verifier.js

첨부 패치:

W04_PACKAGE_VERIFIER_JSON_REPORT_FIX.diff

패치를 검토한 후 동일 의미로 적용한다.

필수 규칙:

1. `TEST_REPORT.json`이 있으면 JSON으로 구조적으로 파싱한다.
2. 다음 조건에서만 PASS:
   - status 또는 overall_status가 정확히 PASS
   - failed 또는 failures가 0
   - cancelled 또는 canceled가 0
3. `"failed": 0` 문자열을 실패로 오판하지 않는다.
4. JSON parse 실패는 FAIL.
5. JSON이 없을 때만 Markdown fallback을 사용한다.
6. Markdown fallback은 bare `fail-closed`, `failed request`, 설명문 속 `failure` 단어만으로 실패 처리하지 않는다.
7. 명시적 status FAIL 또는 1 이상의 실패 개수만 실패로 처리한다.
8. 검증기 기대값을 완화해 실제 실패를 통과시키면 안 된다.

────────────────────────────────
V. 검증기 회귀시험
────────────────────────────────

최소 다음 시험을 추가한다.

1. `{"status":"PASS","failed":0,"cancelled":0}` → PASS
2. `{"overall_status":"PASS","failures":0}` → PASS
3. `{"status":"FAIL","failed":0}` → FAIL
4. `{"status":"PASS","failed":1}` → FAIL
5. `{"status":"PASS","cancelled":1}` → FAIL
6. JSON parse 오류 → FAIL
7. Markdown `status: PASS`, `failed: 0` → PASS
8. Markdown `fail-closed safety verified` → PASS
9. Markdown `status: FAIL` → FAIL
10. Markdown `1 failed` → FAIL

기존 W4 31개 시험을 삭제하거나 완화하지 않는다.

────────────────────────────────
VI. production upstream gate
────────────────────────────────

교정 후 실제 명령을 실행한다.

```bash
node tools/verify_upstream.js \
  --w1 W01_SITE_SCANNER_CORE_CORRECTED.zip \
  --w1-sha 5794e83d002587eaea3ffed2fa3a859e0f9d650038d4a34e440af3c72e0583f9 \
  --w2 W02_SITE_SCANNER_NETWORK_MRI_CORRECTED.zip \
  --w2-sha 504c631d68a4a6a786734fbd90ea804511c75bae396b2543b72285b95576cb91 \
  --w3 W03_SITE_SCANNER_UI_ROUTE_MRI_CORRECTED.zip \
  --w3-sha b6364a7693532ccf7eed7086bff1e6823348d1bf6608c511fb50d1c78a12d461 \
  --out integration/PRODUCTION_UPSTREAM_VERIFICATION.json
```

완료조건:

- 전체 status PASS
- W1 PASS
- W2 PASS
- W3 PASS
- errors 전부 빈 배열

이 결과가 나오기 전 source tree 병합 금지.
