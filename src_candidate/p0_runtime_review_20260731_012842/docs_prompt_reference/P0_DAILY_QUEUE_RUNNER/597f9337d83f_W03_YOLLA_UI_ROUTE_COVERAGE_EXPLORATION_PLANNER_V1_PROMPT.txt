===== W03_YOLLA_UI_ROUTE_COVERAGE_EXPLORATION_PLANNER_V1_PROMPT_START =====

[공통프롬프트]

반드시 `YOLLA_SITE_SCANNER_WAVE2_COMMON_CONTRACT_V1.md`를 최우선으로 적용한다.

너는 “욜라 사이트 스캐너 Wave 2”의 3번 워커다.

담당 제품:

욜라 UI·라우트 커버리지 및 안전 탐색계획기  
YOLLA UI Route Coverage and Safe Exploration Planner

버전:

V1.0.0

목표:

UI·Route MRI가 기록한 페이지 상태·라우트 그래프·탭·필터·폼·페이지네이션·지도·selector 후보를 분석하여 현재 스캔의 커버리지, 아직 방문하지 않은 상태·동작, selector 안정성, 화면구조 변화를 계산하고 사용자 승인 기반의 안전 탐색계획을 생성한다.

이번 작업에서 실제 사이트를 자동으로 대량 탐색하지 않는다.

기본 출력은 “계획”이다.

I. 기준 입력
────────────────────────────────

`b6364a7693532ccf7eed7086bff1e6823348d1bf6608c511fb50d1c78a12d461`

기준 ZIP을 수정하지 않는다.

별도 애드온으로 개발한다.

────────────────────────────────
II. 입력
────────────────────────────────

- UI Route MRI report
- route graph
- page states
- control catalog
- selector catalog
- form catalog
- repeated patterns
- map candidates
- W2 endpoint correlation
- scan package
- 이전 시점 UI baseline
- safety policy

────────────────────────────────
III. 커버리지
────────────────────────────────

계산영역:

- route coverage
- page type coverage
- control coverage
- tab coverage
- filter coverage
- form coverage
- pagination coverage
- infinite scroll coverage
- modal·drawer coverage
- map interaction coverage
- list→detail coverage
- brokerage path coverage
- contact path coverage
- error·empty·loading state coverage

각 영역:

- observed
- inferred total
- unresolved
- blocked
- not applicable
- confidence
- evidence refs

추정 total의 불확실성을 표시한다.

────────────────────────────────
IV. 미탐색 후보
────────────────────────────────

후보 생성근거:

- 발견된 링크이나 방문되지 않음
- tab이나 filter control 미실행
- pagination next 존재
- route parameter variation
- modal trigger
- map zoom·drag
- list item detail
- brokerage detail
- empty state·error state 후보
- W2 endpoint가 있으나 연결 UI 미확인
- UI가 있으나 관련 W2 endpoint 미확인

후보를 자동 실행하지 않는다.

────────────────────────────────
V. 안전 탐색계획
────────────────────────────────

action class:

- SAFE_NAVIGATION
- SAFE_FILTER
- SAFE_PAGINATION
- SAFE_SCROLL
- USER_CONFIRM_REQUIRED
- DESTRUCTIVE_OR_MUTATING
- UNKNOWN

계획에는 SAFE 계열만 자동실행 가능 후보로 넣는다.

`USER_CONFIRM_REQUIRED`는 승인대기.

나머지는 계획에서 실행불가.

각 step:

- step_id
- parent state
- expected target
- trigger selector
- fallback selectors
- action type
- safety class
- expected network
- timeout
- success criteria
- rollback navigation
- evidence
- priority
- coverage gain estimate

────────────────────────────────
VI. 우선순위
────────────────────────────────

점수요소:

- 예상 coverage 증가
- 중개업소·매물 핵심경로
- endpoint와의 상관관계
- selector 안정성
- 동작 안전성
- 비용·시간
- 중복경로
- 미확인 중요도

높은 위험 또는 낮은 selector 안정성은 감점한다.

────────────────────────────────
VII. Selector 안정성
────────────────────────────────

시점별 비교:

- selector 존재
- match count
- uniqueness
- data attribute
- ARIA
- ID
- class entropy
- DOM depth
- nearby label
- fallback success

결과:

- STABLE
- PROBABLY_STABLE
- VOLATILE
- BROKEN
- UNKNOWN

하나의 selector만 저장하지 않는다.

fallback chain과 근거를 유지한다.

────────────────────────────────
VIII. UI·Route drift
────────────────────────────────

변화:

- ROUTE_ADDED
- ROUTE_REMOVED
- PAGE_STATE_CHANGED
- CONTROL_ADDED
- CONTROL_REMOVED
- SELECTOR_BROKEN
- TAB_STRUCTURE_CHANGED
- FILTER_CHANGED
- PAGINATION_CHANGED
- MODAL_FLOW_CHANGED
- MAP_LIBRARY_CHANGED
- LIST_DETAIL_FLOW_CHANGED
- SAFETY_CLASS_CHANGED

severity:

- INFO
- MINOR
- MAJOR
- CRITICAL

파괴적 동작이 안전으로 바뀌었다는 관찰만으로 자동허용하지 않는다.

────────────────────────────────
IX. 실행 어댑터
────────────────────────────────

기본은 계획 JSON만 생성한다.

선택형 executor adapter는 다음 인터페이스만 작성한다.

```javascript
preparePlan(plan)
requestApproval(step)
executeApprovedStep(step)
verifyOutcome(step)
checkpoint()
stop()
```

실제 W1 core의 `requestUserApproval()`을 통해서만 실행한다.

독립 애드온에서는 mock executor만 제공한다.
