===== W07_YOLLA_ADAPTER_COMPILER_DABANG_REFERENCE_V1_PROMPT_START =====

너는 “욜라 부동산 데이터 엔진” 프로젝트의 7번 워커다.

담당 제품:

욜라 사이트 어댑터 생성기
YOLLA Site Adapter Compiler

버전:

V1.0.0

이번 작업의 목적은 다방 전용 수집기를 별도로 만드는 것이 아니다.

1~4번 워커의 “욜라 사이트 스캐너”가 만든 MRI 보고서와 사이트 어댑터 청사진을 읽어, 6번 워커의 “욜라 사이트 수집기 공통 코어”에서 실행할 수 있는 선언형 사이트 어댑터로 변환하는 범용 어댑터 생성기를 완성하는 것이다.

다방은 생성기의 첫 번째 실전 참조 사이트다.

최종 결과는 다음 구조가 되어야 한다.

욜라 사이트 스캐너
→ 사이트 MRI 보고서
→ 사이트 어댑터 청사진
→ W07 어댑터 생성기
→ 공동 수집기용 실행 어댑터
→ W06 욜라 사이트 수집기
→ 욜라 표준 관찰 데이터

────────────────────────────────
I. 역할 경계
────────────────────────────────

7번 워커가 담당한다.

1. 스캐너 청사진 입력 검증
2. 청사진을 공동 수집기 계약으로 변환
3. 선언형 어댑터 생성
4. 사이트별 정규화·필드 매핑 모듈 생성
5. 어댑터 fixture와 단위시험 생성
6. 다방을 첫 번째 참조 어댑터로 적용
7. 어댑터 생성결과의 결정성 검증
8. 어댑터와 증거 사이 추적성 유지
9. W06 공통 코어와의 mock 호환성 검증
10. 구조가 미확인된 항목을 TODO·UNRESOLVED로 보존

7번 워커가 담당하지 않는다.

1. W06 공통 수집기 코어 재작성
2. 다방 전용 수집기 전체 제작
3. 사이트 원본 데이터를 대량 수집
4. 공식 중개업소 마스터 생성
5. 공식 원장과 플랫폼 프로필의 최종 매칭
6. 사이트 간 데이터 병합
7. 중개업소 전문등급 계산
8. 매물 점수 계산
9. 사용자 추천점수 계산
10. 인증·차단·CAPTCHA 우회

V. CLI
────────────────────────────────

Python CLI를 제공한다.

예:

python -m yolla_adapter_compiler verify-input \
  --scanner-report site_scanner_report_dabang.json \
  --blueprint site_adapter_blueprint_dabang.json \
  --manifest scan_manifest.json

python -m yolla_adapter_compiler compile \
  --scanner-report site_scanner_report_dabang.json \
  --blueprint site_adapter_blueprint_dabang.json \
  --collector-contract collector_adapter_v1.schema.json \
  --output-dir adapters/dabang

python -m yolla_adapter_compiler validate \
  --adapter adapters/dabang/adapter.json

python -m yolla_adapter_compiler generate-tests \
  --adapter adapters/dabang/adapter.json \
  --output-dir tests/generated/dabang

python -m yolla_adapter_compiler compare \
  --old-adapter adapters/dabang/v1/adapter.json \
  --new-blueprint site_adapter_blueprint_dabang_new.json

기본은 verify와 dry compile이다.

XI. 정규화
────────────────────────────────

정규화 함수는 순수함수로 작성한다.

후보:

- normalizeRegistrationNumber
- normalizePhone
- normalizePrice
- normalizeArea
- normalizeFloor
- normalizeDate
- normalizeAddress
- normalizePropertyType
- normalizeTransactionType

원문을 삭제하지 않는다.

정규화 실패는 null과 오류코드로 반환한다.

공개 휴대전화와 사무실 전화는 수집대상이다.

전화번호 단독 identity key 생성 금지.

────────────────────────────────
XII. Identity와 Dedupe
────────────────────────────────

플랫폼 중개업소 우선키:

1. 실제 플랫폼 중개업소 ID
2. 안정적인 프로필 URL ID
3. 제한된 fallback key

플랫폼 매물 우선키:

1. 실제 플랫폼 매물 ID
2. canonical source URL
3. 제한된 fallback key

금지:

- 전화번호 단독 중개업소 ID
- 상호 단독 중개업소 ID
- 등록번호 단독 공식 중개업소 확정
- 다른 플랫폼과의 dedupe
- 동일 실물 매물 최종 병합

XIX. 완료상태
────────────────────────────────

다음 중 하나를 사용한다.

PASS

모든 실제 입력과 W06 통합·다방 smoke test까지 통과.

PASS_WITH_WARNINGS

핵심기능은 통과했으나 비치명적 미확인 항목 존재.

COMPILER_COMPLETE_W06_INTEGRATION_PENDING

생성기는 완성됐지만 W06 최종 결과가 없어 실제 통합대기.

DABANG_ADAPTER_PENDING_SCANNER_RESULT

생성기는 완성됐지만 실제 다방 스캔 결과가 없어 참조 어댑터 대기.

PARTIAL_RESULT

핵심 기능 또는 필수시험 미완료.

BLOCKED_BY_SCANNER

BLOCKED_BY_W06

BLOCKED_BY_SCHEMA

SOURCE_SHA_MISMATCH

시험 실패가 있으면 PASS라고 보고하지 않는다.
