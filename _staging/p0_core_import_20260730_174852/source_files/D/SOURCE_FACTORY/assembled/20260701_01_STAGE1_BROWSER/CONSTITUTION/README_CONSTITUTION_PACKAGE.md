# SOURCE FACTORY FILE COMBINATION CONSTITUTION PACKAGE v1.0

이 패키지는 사용자가 새 Commander를 지정할 때 제공할 공식 규칙 묶음입니다.

## 포함 파일

```text
SOURCE_FACTORY_FILE_COMBINATION_CONSTITUTION_v1.md
SOURCE_FACTORY_COMMANDER_COMPLIANCE_RULES_v1.md
CURRENT_SOURCE_REVIEW_MUST_FOLLOW.md
FILE_COMBINATION_RULE_SCHEMA_v1.json
NEW_COMMANDER_START_PROMPT_v1.txt
```

## 설치 권장 위치

```text
D:\SOURCE FACTORY\_CONSTITUTION
```

## 새 Commander에게 제공할 때

아래 순서로 제공하십시오.

1. `SOURCE_FACTORY_FILE_COMBINATION_CONSTITUTION_v1.md`
2. `SOURCE_FACTORY_COMMANDER_COMPLIANCE_RULES_v1.md`
3. `CURRENT_SOURCE_REVIEW_MUST_FOLLOW.md`
4. `NEW_COMMANDER_START_PROMPT_v1.txt`

## 핵심 변경

- 실시간 감시는 공식 완료 기준에서 제외한다.
- 파일결합은 사용자의 컴퓨터 상태를 바꾸는 모든 작업이다.
- 작업 완료는 소스 생성이 아니라 Assembly Record 생성이다.
- 모든 결합은 `_ASSEMBLY_RECORDS/YYYY-MM-DD/TASK_ID_TITLE/` 아래 증거와 보고서를 남긴다.
