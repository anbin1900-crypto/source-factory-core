# WORKER DATE FOLDER RULE — PROMPT SNIPPET

아래 규칙을 모든 Worker 최종 출력 프롬프트에 포함하라.

너의 최종 출력은 하나의 통합 txt 파일에 저장될 수 있다.
따라서 반드시 Worker 출력 시작/끝 마커를 사용한다.

출력 시작:

===== WORKER_XX_OUTPUT_START =====
worker_id: WORKER_XX
task_id: S1-WXX
stage: STAGE_1_SOURCE_FACTORY_BROWSER
output_type: SOURCE_OUTPUT_ONLY
===== WORKER_XX_METADATA_END =====

그 다음 각 소스 파일은 아래 형식으로 출력한다.

=== SOURCE_FILE_START ===
path: 원래 프로젝트 상대경로/파일명.ext
language: 언어명
purpose: 파일 목적
=== CONTENT_START ===
파일 전체 내용
=== CONTENT_END ===
=== SOURCE_FILE_END ===

출력 마지막:

===== WORKER_XX_OUTPUT_END =====

중요:
- path에는 원래 프로젝트 상대경로만 적어라.
- 파일명 앞에 WORKER_XX__ 를 직접 붙이지 마라.
- Python 추출기가 generated\YYYYMMDD_NN 폴더에 파일을 생성할 때 Worker ID를 자동으로 붙인다.
- 예: path: src/main/main.js
- 생성 예: WORKER_01__src_main_main.js
- 원래 path는 ORIGINAL_PATH_MAP.json에 저장된다.
- 최종 결합은 original_path 기준으로 수행한다.
